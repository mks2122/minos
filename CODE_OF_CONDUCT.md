# Code of conduct

minos adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. The full text at that link applies to everyone taking part in
the project: in issues, pull requests, discussions, and anywhere else you represent
it.

In short:

- **Be respectful.** Disagree with ideas, not people. Assume good faith.
- **Be welcoming.** People arrive with different backgrounds, levels of experience
  and first languages. A question that seems basic is still a fair question.
- **Be constructive.** Review the code, explain the concern, suggest the fix.
- **No harassment.** No insults, personal attacks, sexualised language or imagery,
  trolling, or publishing anyone's private information. None of it, in any form.

## Reporting

If someone's behaviour worries you, contact the maintainer privately through
GitHub: [@mks2122](https://github.com/mks2122). Please include links to what
happened, if there are any. Reports are kept confidential.

For security vulnerabilities, use the process in [SECURITY.md](SECURITY.md#reporting-a-vulnerability)
instead.

## Enforcement

The maintainer will review every report and respond with the consequences the
Contributor Covenant describes, from a private warning to a permanent ban,
depending on how serious it is and whether it has happened before.
